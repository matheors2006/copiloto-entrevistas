# CLAUDE.md

Directrices para trabajar en este proyecto.

## Descripción del proyecto

Este proyecto es un **Copiloto de Entrevistas**, compuesto por:

- **Backend**: Python (FastAPI + procesamiento de Audio).
- **Frontend/App**: Tauri (Rust/React).

## Idioma

- Todas las explicaciones, respuestas y comunicación dirigidas al usuario deben estar en **Español**.
- Todo el código fuente (nombres de variables, funciones, clases, comentarios dentro del código, mensajes de commit, etc.) debe estar en **Inglés**.

## Entorno de desarrollo

- Antes de ejecutar cualquier comando de instalación de dependencias (pip, npm, cargo, etc.), verificar primero si el entorno virtual (venv) está activo.
- Si el entorno virtual no está activo, activarlo antes de continuar con la instalación.
